# 심사위원용 데모 가이드

## 공개 영상

[2분 웹 제품 워크스루](https://github.com/blockcoder-sj/fancy-showcase/releases/download/v1.0-showcase/fancy-web-showcase.mp4)는 공연 탐색, 좌석도, 좌석 선택과 수령자 단계 진입을 보여줍니다. 로컬 테스트 데이터만 포함하고 개인정보 입력 전 구간에서 종료합니다.

## 3분 라이브 시연 권장 순서

| 시간 | 화면 | 보여줄 내용 | 평가 포인트 |
|---:|---|---|---|
| 0:00 | Web | Google 로그인 후 공연 선택 | 실제 사용자 흐름 |
| 0:20 | Web | 좌석도에서 여러 좌석 선택 | 좌석 재고와 hold |
| 0:45 | Web | 다른 수령자만 이메일 입력, 빈 좌석은 대표자에게 배정 | 다중 티켓 UX |
| 1:05 | Mobile | 푸시 알림에서 앱 승인 화면 진입 | 웹·앱 연동 |
| 1:25 | Mobile | OS 생체 인증 후 티켓 묶음 바인딩 | 하드웨어 키 경계 |
| 1:50 | Wallet | 공연 1주 전부터 티켓 열기, 동적 QR 확인 | 사용성 + 서버 상태 |
| 2:15 | Scanner | 스태프 계정으로 첫 스캔 승인, 재스캔 거절 | 권한 + 원자적 1회 입장 |
| 2:40 | Mobile | 새 생체 등록 후 기존 키 무효화·티켓 잠금 | 암표 방지 핵심 |

## 발표용 한 문장

> FANcy는 QR 이미지를 숨기는 서비스가 아니라, 입장 권리를 검증된 사용자·휴대폰·하드웨어 키에 묶고 서버가 한 번만 승인하는 티켓 시스템입니다.

## 시연 전 체크

- 전용 테스트 Google 계정과 공연·좌석을 사용합니다.
- 알림 권한, 네트워크, API 상태와 스태프 게이트 할당을 확인합니다.
- 개인 이메일, 실제 결제키, QR 원문, 내부 URL이 녹화 화면에 보이지 않게 합니다.
- 화면 녹화를 위해 개발 전용 캡처 허용을 사용했다면 릴리스 설정과 분리되었음을 설명합니다.
- 실패 상황도 준비합니다: 만료 QR, 재사용 QR, 권한 없는 스태프, 무효화된 키.
