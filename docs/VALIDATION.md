# 검증 보고서

기준일: 2026-09-10  
기준: 앱·웹 제출 브랜치의 최신 공개 전 검증

## 자동 검사

| 대상 | 결과 |
|---|---:|
| Ticket API | 188 tests passed |
| React Native mobile | 238 tests passed |
| Attestation verifier | 18 tests passed |
| Web | 551 tests passed |
| 합계 | **995 tests passed** |

앱 모노레포와 웹 모두 TypeScript typecheck와 ESLint를 통과했습니다. 웹 마이그레이션 인벤토리도 89개 파일과 문서가 일치하는지 확인했습니다.

웹 테스트 63개는 로컬 Supabase 통합 환경이 활성화된 실행에서만 동작하며, 이 기준 실행에서는 skip되었습니다. 따라서 이 문서에서는 해당 63개를 통과 수치에 포함하지 않습니다.

## 실기기 확인

Android 실기기에서 다음을 확인했습니다.

- 웹과 앱의 동일 Google 계정 연결
- 앱 푸시에서 티켓 승인 흐름 진입
- Android Keystore 하드웨어 키와 원격 검증 결과 연결
- 생체 승인 후 challenge 서명
- 티켓 지갑 상태와 웹 상태 투영
- 새 생체 등록 이후 기존 키 무효화와 티켓 잠금
- 잠긴 티켓에서 입장 QR 발급 거절

## 공개 전 점검

- 공개 대상 파일에 `.env`, 토큰, 서비스 역할 키, 개인키가 없는지 검사
- 스크린샷에 이메일·실제 QR·활성 티켓 식별자가 없는지 육안 검토
- 공개 영상은 개인정보가 입력되기 전 구간만 별도 변환
- 앱·웹 원본 저장소와 전체 Git 이력은 제외

## 주장하지 않는 것

- 독립 기관의 보안 인증 완료
- 실제 운영 결제·대규모 부하·재해 복구 검증 완료
- 모든 Android 제조사에서 동일한 생체 변경 이벤트 제공
- 프로덕션 출시 준비 완료

FANcy는 현재 대회 시연이 가능한 통합 프로토타입이며, 운영 출시 전 별도의 외부 E2E·보안·법무 검토가 필요합니다.
